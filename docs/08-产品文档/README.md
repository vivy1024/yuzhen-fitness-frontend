## 产品策略说明

### 当前策略（MVP测试阶段）

**完全免费 + 打赏支持**:
- 免费版：每天10次AI对话，完整13个AI场景
- 训练计划最多保存5个
- 打赏支持：自愿打赏，金额随意
- 打赏后可获得更多AI对话次数

### 为什么采用这种策略

1. **合规考虑**: 个人开发者，没有企业资质，域名备案中（个人备案不能涉及经营性业务）
2. **MVP测试**: 需要更多用户测试所有AI场景，收集真实反馈
3. **降低门槛**: 让用户先体验完整功能，满意后再打赏支持

### 未来规划

企业资质办好后（预计2026年2月），会推出正式会员体系：
- 免费版：基础功能
- 暖心会员：¥6/月，更多对话次数和训练计划
- 能量会员：¥29.9/月，无限对话，Agent模式

详见：[产品介绍 - 会员体系](./02-产品介绍.md#会员体系)
