## 系统概述

玉珍健身采用四层架构：前端 PWA → YuzhenFork Agent → DAML-RAG 工具引擎 → Laravel 后端。AI 对话通过 WebSocket 实时通信，Agent 通过 MCP 协议调用 25 个专业工具。

```
┌─────────────────────────────────────────────────────────────────┐
│                        用户设备                                    │
│  ┌─────────────────────────────────────────────────────────┐     │
│  │              前端 PWA (Vue 3 + TypeScript)               │     │
│  │                    localhost:9000                         │     │
│  │  • AI 对话（WebSocket）  • 训练记录  • 动作库  • 食物库   │     │
│  └─────────────────────────────────────────────────────────┘     │
└─────────────────────────────────────────────────────────────────┘
                    │ WebSocket              │ HTTP REST
                    ▼                        ▼
┌───────────────────────────┐    ┌──────────────────────────────┐
│  YuzhenFork Studio        │    │  Laravel 后端                  │
│  (Bun, port 4600)         │    │  (PHP, Docker, port 8000)     │
│                           │    │                               │
│  • 健身教练 System Prompt  │    │  • 用户认证 / 会员系统         │
│  • 14 个 Skill 定义        │    │  • 训练记录 / 训练计划         │
│  • DeepSeek LLM           │    │  • 内部 API（供 DAML-RAG）     │
│  • Session 管理            │    │                               │
└─────────────┬─────────────┘    └──────────────────────────────┘
              │ MCP stdio                        ▲
              ▼                                  │ HTTP
┌───────────────────────────────────────────────┐│
│  DAML-RAG Server (Python, Docker, port 8001)  ││
│                                               ││
│  • 25 个 MCP 工具                              ││
│  • 浪潮引擎（向量检索 + 图谱推理 + 安全过滤）    ││
│  • 5,780 知识 chunks                           ││
│  • 1,790 动作 + 1,880 食物                     ││
```

## 技术栈

| 层 | 技术 | 说明 |
|---|------|------|
| 前端 | Vue 3 + TypeScript + Vite + Tailwind | PWA，移动端优先 |
| Agent | Bun + TypeScript (YuzhenFork/NovelFork) | Skills-first Agent |
| AI 引擎 | Python + gte-large-zh + Qdrant + Neo4j | 向量+图谱混合检索 |
| 后端 | Laravel 11 + MySQL + Redis | 业务逻辑 + 数据持久化 |
| LLM | DeepSeek Chat (function calling) | 通过 OpenAI 兼容 API |

---

## 通信协议

| 链路 | 协议 | 说明 |
|------|------|------|
| 前端 ↔ YuzhenFork | WebSocket | 实时对话（session:stream/message/state） |
| 前端 → Laravel | HTTP REST | 认证/训练记录/计划/食物/动作 |
| YuzhenFork → DAML-RAG | MCP stdio | 25 个工具调用 |
| DAML-RAG → Laravel | HTTP 内部 API | 用户档案/训练记录（X-Internal-Token） |
