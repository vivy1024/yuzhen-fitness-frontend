## 📋 概述

本文档详细说明玉珍健身前端项目从v2版本到当前版本的重构过程，重点介绍基于shadcn-vue的新架构设计和实现细节。

### 重构背景

**v2版本存在的问题**：
- 同时使用两种UI库（Element Plus + 自建组件），导致样式冲突
- 大量自建UI组件，重复造轮子，维护成本高
- 组件库不统一，用户体验不一致
- 缺乏完整的设计系统

**重构目标**：
- 统一UI组件库，使用shadcn-vue
- 减少自建组件，提高开发效率
- 建立完整的设计系统
- 提升用户体验和可访问性

### shadcn-vue 简介

**shadcn-vue** 是基于 Radix UI 的 Vue 3 组件库，特点：
- ✅ **无依赖**：组件代码直接复制到项目中，完全可控
- ✅ **可定制**：基于Tailwind CSS，样式完全可定制
- ✅ **可访问性**：遵循WCAG 2.1 AA标准
- ✅ **TypeScript**：完整的类型支持
- ✅ **组合式API**：使用Vue 3 Composition API

**与传统组件库的区别**：

| 特性 | 传统组件库 | shadcn-vue |
|------|-----------|-----------|
| 安装方式 | npm install | 复制组件代码 |
| 依赖管理 | 依赖包 | 无外部依赖 |
| 定制性 | 有限 | 完全可控 |
| 打包体积 | 较大 | 按需使用 |
| 更新方式 | npm update | 手动更新 |

```vue
<script setup lang="ts">

import { useChatStream } from '@/composables/useChatStream'
import { Button } from '@/components/ui/button'
import { Input } from '@/components/ui/input'
import MessageList from '@/components/chat/MessageList.vue'

const { messages, sendMessage, isStreaming } = useChatStream()
const inputText = ref('')

const handleSend = async () => {
  if (!inputText.value.trim()) return
  await sendMessage(inputText.value)
  inputText.value = ''
}
</script>

<template>
  <div class="flex flex-col h-screen">
    <MessageList :messages="messages" class="flex-1 overflow-y-auto" />
    <div class="p-4 border-t">
      <div class="flex gap-2">
        <Input 
          v-model="inputText" 
          placeholder="输入消息..." 
          @keyup.enter="handleSend"
        />
        <Button 
          @click="handleSend" 
          :disabled="isStreaming"
        >
          发送
        </Button>
      </div>
    </div>
  </div>
</template>
```

### Store示例

```typescript
// stores/auth.ts
import { defineStore } from 'pinia'
import { ref, computed } from 'vue'
import type { User } from '@/types'

export const useAuthStore = defineStore('auth', () => {
  // State
  const user = ref<User | null>(null)
  const token = ref<string | null>(null)
  
  // Getters
  const isAuthenticated = computed(() => !!token.value)
  const isAdmin = computed(() => user.value?.role === 'admin')
  
  // Actions
  const login = async (email: string, password: string) => {
    const response = await api.post('/auth/login', { email, password })
    token.value = response.data.token
    user.value = response.data.user
  }
  
  const logout = () => {
    token.value = null
    user.value = null
  }
  
  return {
    user,
    token,
    isAuthenticated,
    isAdmin,
    login,
    logout
  }
}, {
  persist: true  // 持久化到localStorage
})
```

### Axios配置

```typescript
// api/index.ts
import axios from 'axios'
import { useAuthStore } from '@/stores/auth'

const api = axios.create({
  baseURL: import.meta.env.VITE_API_BASE_URL,
  timeout: 10000
})

// 请求拦截器：添加Token
api.interceptors.request.use(config => {
  const authStore = useAuthStore()
  if (authStore.token) {
    config.headers.Authorization = `Bearer ${authStore.token}`
  }
  return config
})

// 响应拦截器：处理错误
api.interceptors.response.use(
  response => response,
  error => {
    if (error.response?.status === 401) {
      // Token过期，跳转登录
      const authStore = useAuthStore()
      authStore.logout()
      router.push('/login')
    }
    return Promise.reject(error)
  }
)

export default api
```
