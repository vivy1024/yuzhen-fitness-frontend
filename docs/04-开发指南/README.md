## 🚀 快速开始

### 开发环境设置

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

### 技术栈

- **框架**: Vue 3 + Vite
- **UI库**: shadcn-vue
- **状态管理**: Pinia
- **路由**: Vue Router
- **HTTP客户端**: Axios
